# Python Programming Internship — Week 1

This directory contains the completed assignments and mini-project for **Week 1** of the Python Programming Internship.

---

## Overview & Table of Contents

### Assignments

1. **[Temperature Converter](temperature_converter.py)**
   - **Description**: Converts temperature values between Celsius and Fahrenheit.
   - **Concepts Used**: Functions, mathematical formulas, conditional branching, user input validation, output formatting.

2. **[Student Grade Calculator](grade_calculator.py)**
   - **Description**: Calculates average student marks across multiple subjects and assigns standard letter grades (A, B, C, D, F).
   - **Concepts Used**: Lists, loops, arithmetic calculations, function decomposition, range validation (0–100).

3. **[Even/Odd & Prime Number Checker](even_odd_prime_checker.py)**
   - **Description**: Determines whether an integer is even or odd, and verifies if it is a prime number.
   - **Concepts Used**: Modulo operator, boolean logic, loops, mathematical algorithms, edge-case validation (`0`, `1`, negative numbers).

### Mini Project

4. **[Simple ATM Simulator](atm_simulator.py)**
   - **Description**: An educational command-line ATM system supporting secure demo PIN login (`1234`), balance checks, deposits, and withdrawals.
   - **Concepts Used**: Modular functions, state management (account balance), while loops, validation against negative values and overdrawing.

---

## Technologies Used

* **Language**: Python 3 (Pure standard library, no external packages)

---

## Concepts Practiced

* **Variables & Data Types**: Strings, integers, floats, booleans, lists
* **Input / Output**: Interactive CLI prompts and formatted string output
* **Functions**: Function definition, parameters, return values, type hinting
* **Conditional Statements**: `if`, `elif`, `else` decision structures
* **Loops**: `while` and `for` iterations
* **Validation & Error Handling**: `try-except` blocks for handling invalid numerical input
* **Modular Programming**: Separating tasks into clean, reusable functions

---

## How to Run

Navigate to the `Week-1` directory and execute any script using the Python interpreter:

```bash
# Assignment 1 - Temperature Converter
python temperature_converter.py

# Assignment 2 - Student Grade Calculator
python grade_calculator.py

# Assignment 3 - Even/Odd & Prime Number Checker
python even_odd_prime_checker.py

# Mini Project - Simple ATM Simulator
python atm_simulator.py
```

## 🗓️ Weekly Modules

### 📖 [Week 1 — Python Basics & Modular Programming](Week-1/README.md)
* **Assignment 1 — Temperature Converter**: Converts Celsius ↔ Fahrenheit using functions.
* **Assignment 2 — Student Grade Calculator**: Calculates subject average and assigns letter grades.
* **Assignment 3 — Even/Odd & Prime Number Checker**: Checks number parity and primality with edge-case handling.
* **Mini Project — Simple ATM Simulator**: Interactive CLI ATM simulator featuring PIN authentication, balance inquiry, deposit, and withdrawal operations.

---

### 📖 [Week 2 — Data Structures, File I/O & Exception Handling](Week-2/README.md)
* **Assignment 1 — Contact Book**: Contact manager using dictionary data structures with full CRUD support.
* **Assignment 2 — Word Counter Tool**: Text file analyzer that calculates word, line, and character counts.
* **Assignment 3 — JSON File Reader**: Reads and pretty-prints JSON files with comprehensive error handling.
* **Mini Project — Student Management System**: Permanent CSV-backed student management system with validation and persistence across reboots.

## 🚀 How to Run

To run any script, navigate into the respective week folder and use Python 3:

```bash
# Example: Running Week 2 Student Management System
cd Week-2
python student_management_system.py
```
